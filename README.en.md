# Golang API
[![ENG]](https://github.com/malaneph/golang-api/blob/master/README.en.md)
[![RUS]](https://github.com/malaneph/golang-api/blob/master/README.md)

Sample REST API service project for aggregating data on users' online subscriptions written in Golang

## Installation

1. Copy the env file and make necessary changes:

   ```bash
   copy example.env .env
   ```

2. Run the command for docker containers:

   ```bash
   docker-compose up -d
   ```

API documentation is available at the /docs route
